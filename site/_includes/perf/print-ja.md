### Web 編集ツールからのプリントが平板に見える理由

テストでは、カメラの写真 20 枚と、その Display P3 版（最近のスマートフォンや Mac の広い色空間）5 枚を Fotollection の実際の書き出しで書き出し、両方のファイルを独立したデコーダーで読み込みます。カラープロファイルを通して CIELAB に変換し、元の写真とピクセルごとに比べます。一般的な Web 編集ツールの書き出しにも同じ比較を行います。プロファイルを削除し、2000 px に縮小してからプリント用に拡大し直し、品質 80、色情報を半分（4:2:0）にして保存したものです。

| 中央値 | Fotollection、sRGB | Web 編集ツール | Fotollection、Display P3 | Web 編集ツール |
|---|---|---|---|---|
| ΔE2000（色の誤差、1 未満は見えない） | 0.19 | 1.39 | 0.31 | 2.15 |
| PSNR | 52.6 dB | 37.9 dB | 50.8 dB | 37.0 dB |
| 残った彩度 | 100% | 99.9% | 99.9% | 86.8% |
| 残った細部 | 99.8% | 13% | 100% | 18% |

平板に見える原因は 2 つです。2000 px への縮小とラボ用の再拡大で、プリントをシャープに見せる細部の 87% が捨てられます。そしてカラープロファイルを削除すると、Display P3 の写真を sRGB として読むことになり、彩度の 13% が失われます。Fotollection はプロファイルを保持し（25 ファイル中 25）、写真のフル解像度、フルカラー（4:4:4）、品質 95 で書き出します（測定時の値。v0.13.0 からの標準は 90 で、それでも見て分かる差を下回ります）。大きめの誤差は、どの JPEG も最も苦労するシャープなエッジにだけ現れます。今後の課題：実際の iPhone の HEIC ファイルと、分光測色計で測ったプリント。
