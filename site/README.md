# Website

The project's website, <https://fotollection.org/>, in nine languages, English (`/`), Czech (`/cs/`), German (`/de/`), French (`/fr/`), Hungarian (`/hu/`), Polish (`/pl/`), Vietnamese (`/vi/`), Korean (`/ko/`) and Japanese (`/ja/`), each language at its own prefix from one list ([`_data/languages.yml`](_data/languages.yml); the home page's community section by language (`community`: Vietnam Linux Family and CaramOS for Vietnamese readers, AlternativeTo and GitHub for everyone else, owner 2026-11-14); Korean at `/ko/`, also `/kr/` (owner, 2026-11-15): its home page on Korea's convenience stores (`kiosk: kr`: CU and GS25, whose photos print at Printing Box kiosks in 4 × 6 inches, 10 × 15 cm, a size built in), its words never broken inside (`:lang(ko)`: `word-break: keep-all`), the system's Korean Gothic, nothing served; Japanese at `/ja/`, also reached as `/jp/` (`aliases`), its home page showing Japan's convenience stores instead of dm and Rossmann (`kiosk: jp`: 7-Eleven, Lawson and FamilyMart, L判, 2L判 and ましかく, their footnotes in `footnotes.yml`'s own `ja` list), its kana and kanji in the system's own Japanese faces (`:lang(ja)` in `site.css`, nothing served), set as Apple's Japanese pages are (owner, 2026-11-14): bold Gothic headings with `palt`, short headlines ending in 。, no typed space between Japanese and Latin (the browser spaces them, `text-autospace`), lines broken by phrase; the Ko-fi button tells, on its second line, how one pays (`support_kofi_sub`, every language), and the note under it how to use Ko-fi's English page (Tip, euros); every language has every page but the story, which is English and Vietnamese only, its link leading to English's in the others). It is built by Eleventy ([`eleventy.config.mjs`](../eleventy.config.mjs), [ADR-0049](../docs/adr/0049-website-on-eleventy.md)) in [`.github/workflows/pages.yml`](../.github/workflows/pages.yml) and served by GitHub Pages whenever `site/` changes on `main`, and after every release, so the download buttons always point at the latest installers ([docs/RELEASE.md](../docs/RELEASE.md)). Every stylesheet and script is linked through the `bust` filter, its path with a hash of its content (`site.css?v=…`), so a browser that kept the old file (Pages: ten minutes) fetches the new one with the new page; `check-docs.sh` refuses such a link through `relative_url`.

**Rules.** The only third-party script is Google Analytics (`google_analytics` in `_config.yml`, production builds only), the owner's choice for counting visits and clicks on the download links; the footer says so, and the visit total in the footer is read from it at build time, not by a script in the page, and the app itself has no analytics. No other third-party scripts, fonts or trackers: support goes through plain links to Ko-fi and GitHub Sponsors, never their widgets (owner, 2026-11-07: a native button works everywhere, blockers included), and the privacy policy says they process the payments; `assets/js/qrcode.js` is a library served from the site itself. Text is plain Liquid output, never raw HTML from data. A new string is added to both languages.

**Address.** The domain `fotollection.org` is registered at Cloudflare (2026-10-25). Its DNS points the apex at GitHub Pages (A `185.199.108–111.153`, AAAA `2606:50c0:8000–8003::153`) and `www` at `hoangphi01.github.io`, all *DNS only* so GitHub can issue the HTTPS certificate. The custom domain is set in the repository's Pages settings (the site deploys through Actions, so no `CNAME` file is used), and the old `hoangphi01.github.io/fotollection/` address redirects to it. Moving it again means changing `url` and `baseurl` in `_config.yml` and the Pages setting.

## Preview locally

```sh
npm ci                     # once: Eleventy and its markdown plugins
scripts/site-manual.sh     # the manual's pages, as the workflow makes them
npm run site:serve         # http://localhost:4000, rebuilt on every save
```

The download buttons and download count need `_data/release.json`, `repo.json` and `downloads.json`, which the workflow writes (`gh api …`, `scripts/download-stats.mjs`); without them the page falls back to links to the releases. The visit count needs the workflow's Google Analytics secrets.
