# Website

The project's website, <https://fotollection.org/>, in English (`/`) and Vietnamese (`/vi/`), each language at its own prefix from one list ([`_data/languages.yml`](_data/languages.yml); Hungarian `/hu/`, German `/de/`, Polish `/pl/` and Czech `/cs/` have the home and Download pages, and lead to English for the others). It is built by Eleventy ([`eleventy.config.mjs`](../eleventy.config.mjs), [ADR-0049](../docs/adr/0049-website-on-eleventy.md)) in [`.github/workflows/pages.yml`](../.github/workflows/pages.yml) and served by GitHub Pages whenever `site/` changes on `main`, and after every release, so the download buttons always point at the latest installers ([docs/RELEASE.md](../docs/RELEASE.md)).

**Rules.** The only third-party script is Google Analytics (`google_analytics` in `_config.yml`, production builds only), the owner's choice for counting visits and clicks on the download links; the footer says so, and the visit total in the footer is read from it at build time, not by a script in the page, and the app itself has no analytics. No other third-party scripts, fonts or trackers: support goes through plain links to Ko-fi and GitHub Sponsors, never their widgets (owner, 2026-11-07: a native button works everywhere, blockers included), and the privacy policy says they process the payments; `assets/js/qrcode.js` is a library served from the site itself. Text is plain Liquid output, never raw HTML from data. A new string is added to both languages.

**Address.** The domain `fotollection.org` is registered at Cloudflare (2026-10-25).
